# いあきゃら → キャラッシュ 変換

いあきゃらの「テキスト出力」（クトゥルフ6版）を、キャラッシュの貼り付けインポート用テキストに変換するツールです。

https://tapielly.github.io/iachara2charash/

## 使い方

1. いあきゃらのマイページで「キャラ出力」→「ファイルに出力」→「テキスト出力」
2. 出てきたテキストをツールの左の欄に貼る（.txt のドロップも可）
3. 右の結果をコピーして、キャラッシュの「＋新規作成」→「貼り付け」欄に貼り、「インポート」

変換はブラウザの中だけで行い、データはどこにも送信しません。

## 制限

- クトゥルフ6版のみ対応
- 武器・所持品・収入・経験の記録は表に変換せず、共通メモに原文のまま入ります
- アイコン画像は移行されません

非公式のツールです。いあきゃら・キャラッシュの運営とは関係ありません。
